# Synetra client preview

Run `npm install` and `npm run dev` for local preview. Run `npm run build` to generate `out/`; serve that directory with a static web server. Google Fonts access is needed at build time; fonts are served locally by Next.js after export.

The preview includes seven marketing pages. Only AI Solutions and Financial Services have detail data. Fill in another entry?s optional `detail` object to enable its page automatically. Navigation, footer and homepage links resolve through the shared href helpers; entries without detail data point to overview anchors.

The supplied brief ends before its referenced brand motifs/design-system details. The proposed direction uses ivory, ink, electric blue, geometric pathways and a code-built wordmark, with Sora headings and Inter body text. Confirm brand direction with the client.

The contact form validates fields and prepares a local, copyable conversation brief. It does not submit or store information. Confirm contact details and connect a submission service before production. No client names, testimonials, performance statistics, certifications or office addresses have been invented.

Reference websites were consulted for subject categories only. All page copy and layouts are new. No stock imagery is used.
